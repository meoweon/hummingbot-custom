# CCI 策略配置工具

欢迎使用 CCI（商品通道指数）配置工具！此工具允许您创建、修改、可视化和保存基于 CCI 的方向性交易策略配置。以下是如何充分利用它的指南。

## 功能特点

- **使用默认配置**: 从默认配置开始，或使用现有配置的值。
- **修改配置值**: 根据您的交易策略需求更改各种参数。
- **可视化结果**: 通过可视化图表查看您的更改的影响。
- **保存和部署**: 满意后，保存配置以供后续部署。

## 使用方法

### 1. 加载默认配置

首先，加载 CCI 策略的默认配置。这提供了一个可以根据需要自定义的基线设置。

### 2. 用户输入

为策略配置输入各种参数。这些参数包括：

- **连接器名称**: 选择交易平台或交易所（例如：binance_perpetual、okx_perpetual等）。
- **交易对**: 选择加密货币交易对（例如：BTC-USDT、ETH-USDT等）。
- **杠杆**: 设置杠杆比率。对于永续合约交易，可以设置为10-20倍，根据您的风险承受能力调整。如果您使用现货交易，请将杠杆设置为1。
- **总额（报价货币）**: 定义您想要分配用于交易的总金额，以报价货币计算（例如：USDT）。
- **每侧最大执行器数量**: 指定每个方向（买入/卖出）可以同时运行的最大执行器数量。较高的数值允许更多的并行交易，但可能增加资金占用。
- **冷却时间**: 设置交易之间的冷却期（以分钟计）。较长的冷却时间可以减少过度交易，而较短的冷却时间可能捕获更多的短期机会。
- **持仓模式**: 选择不同的持仓模式。
  - **对冲模式(HEDGE)**: 允许同时持有同一交易对的多头和空头头寸。这种模式适合复杂的交易策略，如套利、对冲和市场中性策略，可以同时从上涨和下跌市场中获利。
  - **单向模式(ONEWAY)**: 在同一时间只允许持有一个方向的头寸（多头或空头）。如果您已有一个方向的头寸，必须先平仓才能开立相反方向的头寸。这种模式适合单一方向交易策略，操作更简单且通常需要较少的保证金。
- **K线连接器**: 选择K线数据的数据源。可以与交易连接器相同，也可以选择其他流动性更好的交易所作为数据源。
- **K线交易对**: 选择用于分析的K线数据交易对。通常与交易的交易对相同，但也可以使用相关性高的其他交易对作为信号源。
- **时间间隔**: 设置K线数据的时间间隔（例如：1m为1分钟，1h为1小时，1d为1天）。较短的时间间隔适合短线交易，较长的时间间隔适合中长线趋势跟踪。
- **CCI长度**: 定义CCI指标计算周期的长度。传统设置为14或20，较小的值对价格变化更敏感，较大的值产生更平滑的CCI线。
- **超买水平**: 设置CCI超买阈值（通常为100或更高）。当CCI上升超过此值时，市场可能被认为是超买状态。
- **超卖水平**: 设置CCI超卖阈值（通常为-100或更低）。当CCI下降低于此值时，市场可能被认为是超卖状态。
- **风险管理**: 设置止损、止盈、时间限制和追踪止损设置的参数（详见三重屏障风险管理方法部分）。

### 3. 信号配置

CCI策略允许您自定义信号的生成方式：

#### 超买设置
- **水平**: 表示超买条件的CCI值（默认：100）。较高的值表示更严格的超买条件，产生更少但可能更可靠的信号。
- **穿越方向**: 选择当CCI在超买水平上方或下方穿越时生成信号。
  - **向上穿越(Cross Above)**: 当CCI从下方穿越超买水平向上时生成信号。
  - **向下穿越(Cross Below)**: 当CCI从上方穿越超买水平向下时生成信号。
- **信号类型**: 选择在触发超买条件时生成买入或卖出信号。
  - **传统上**，超买条件通常会生成卖出信号，因为市场可能超买，但您可以根据自己的策略自定义。

#### 超卖设置
- **水平**: 表示超卖条件的CCI值（默认：-100）。较低的值（如-150）表示更严格的超卖条件。
- **穿越方向**: 选择当CCI在超卖水平上方或下方穿越时生成信号。
  - **向上穿越(Cross Above)**: 当CCI从下方穿越超卖水平向上时生成信号（传统用法）。
  - **向下穿越(Cross Below)**: 当CCI从上方穿越超卖水平向下时生成信号。
- **信号类型**: 选择在触发超卖条件时生成买入或卖出信号。
  - **传统上**，超卖条件通常会生成买入信号，因为市场可能超卖，但您可以根据自己的策略自定义。

#### 仅在K线收盘时生成信号
- 启用此选项时，信号只会在K线收盘时生成，这有助于减少假信号并避免因未完成K线的价格波动而产生的错误信号。
- 对于较短的时间间隔（如1分钟、3分钟）可以考虑禁用此选项以捕获更多信号，而对于较长的时间间隔（如1小时、4小时），建议启用此选项以提高信号质量。

### 4. 可视化指标

在交易界面上可视化CCI指标，以查看您的配置的影响。以下是一些帮助您微调指标的提示：

- **CCI长度**: 较大的长度会使CCI指标更平滑，对短期价格波动的敏感度较低，而较小的长度会使其对最近的价格变化更敏感。通常，14-20的周期适用于大多数市场。
- **超买/超卖水平**: 传统值为+100/-100，但在波动性较大的市场中，您可能需要更高的阈值（如+150/-150）以避免过早进入交易。
- **可视化天数**: 默认显示过去1天的数据进行分析。您可以根据需要调整此值，查看更长时间范围内的CCI表现，帮助识别适合您策略的模式。

### 5. 交易信号说明

CCI V1策略使用商品通道指数（CCI）根据您的配置生成交易信号：

- **信号生成**: 当CCI以指定方向穿越超买或超卖水平时生成信号。
- **信号类型**: 您可以配置穿越每个水平时是生成买入还是卖出信号，允许灵活的策略设计。
- **传统设置**: 在传统设置中：
  - 超卖区域向上穿越生成买入信号（市场从超卖状态恢复）
  - 超买区域向下穿越生成卖出信号（市场从超买状态回落）
- **反转策略**: 您也可以设置反向信号生成方式，例如：
  - 超卖区域向下穿越生成买入信号（捕捉极端超卖状态）
  - 超买区域向上穿越生成卖出信号（捕捉极端超买状态）

### 6. 执行器分配

报价货币的总额将在最大执行器数量之间平均分配。例如，如果总额为1000 USDT，每侧最大执行器数量为5，则每个执行器将有200 USDT用于交易。

当触发信号时：
1. 第一个执行器将下单并开始跟踪该头寸
2. 系统将等待冷却时间经过
3. 如果在冷却时间后再次触发信号，第二个执行器将被激活，以此类推
4. 每个执行器独立管理自己的头寸，应用三重屏障风险管理系统

这种设计允许系统在不同时间点以不同价格水平分批进行交易，而不是一次性投入全部资金，从而降低市场冲击和时间风险。

### 7. 保存配置

一旦您对配置和可视化结果感到满意，就可以保存配置以供将来使用。这样您就可以在不需要重新配置的情况下部署相同的策略。

### 8. 三重屏障风险管理方法

CCI V1策略集成了强大的风险管理功能，采用三重屏障方法（Triple Barrier Method）来控制每个交易的风险和回报。这种方法最初由Marcos López de Prado在其著作《Advances in Financial Machine Learning》中提出，为每个交易设置了三个独立的"屏障"，决定何时退出交易。

#### 三重屏障的组成部分

1. **止损（Stop Loss）屏障**:
   - 作用：当价格朝不利方向移动超过特定百分比时触发平仓，限制最大损失。
   - 配置：以百分比设置（例如，3%表示价格不利移动3%时将退出交易）。
   - 应用场景：设置为交易资本的1-5%是常见做法，具体取决于您的风险承受能力。在波动性较高的市场中，可能需要更宽的止损。

2. **止盈（Take Profit）屏障**:
   - 作用：当价格朝有利方向移动达到特定目标时触发平仓，锁定利润。
   - 配置：以百分比设置（例如，2%表示价格有利移动2%时将获利了结）。
   - 应用场景：通常设置为止损的0.5-1.5倍。若风险回报比为1:2，则止损3%时，止盈应为6%。

3. **时间限制（Time Limit）屏障**:
   - 作用：设置交易的最长持有时间，无论盈亏如何，到期后自动平仓。
   - 配置：以秒为单位设置（例如，2700秒等于45分钟）。
   - 应用场景：防止交易被无限期持有；尤其适用于短期波动交易以及防止过夜风险。对于CCI短线交易，通常设置为几小时至一天。

4. **追踪止损（Trailing Stop）**:
   - 作用：随着价格向有利方向移动而动态调整止损水平，保护已获利润同时允许收益继续增长。
   - 配置：包含两个参数：
     - **激活价格差值**：价格必须向有利方向移动这个百分比才激活追踪止损（例如，1.5%）。
     - **跟踪差值**：一旦激活，价格回撤这个百分比时将触发平仓（例如，0.3%）。
   - 应用场景：特别适合趋势交易，能在保护利润的同时让利润奔跑。

#### 三重屏障在CCI策略中的实现

CCI策略通过Position Executor（位置执行器）实现三重屏障方法：

1. **信号生成与执行流程**:
   - CCI指标穿越超买/超卖水平时生成信号。
   - 控制器创建执行器并配置三重屏障参数。
   - 执行器负责开仓，并实时监控三重屏障条件。
   - 一旦触及任何屏障，执行器自动平仓并记录交易结果。

2. **参数配置建议**:
   - **震荡市场**：较小的止损（1-3%）和相应的止盈（2-6%），较短的时间限制（几小时内）。
   - **趋势市场**：较大的止损（3-5%），激进的追踪止损设置，较长的时间限制以捕获完整趋势。
   - **高波动市场**：适当放宽止损（4-6%），保守的止盈（8-12%），慎用追踪止损。

3. **应用实例**:
   假设在ETH-USDT交易对上，基于CCI信号进行买入交易：
   - 止损设置为3%（价格下跌3%时平仓）
   - 止盈设置为4.5%（价格上涨4.5%时平仓）
   - 时间限制设为3600秒（1小时）
   - 追踪止损激活在2%，跟踪差值为0.5%

   在这个配置下：
   - 如果ETH价格在1小时内下跌3%，止损触发，交易关闭
   - 如果ETH价格上涨4.5%，止盈触发，交易关闭
   - 如果ETH价格上涨超过2%，追踪止损激活，如果之后价格回撤0.5%，交易关闭
   - 如果1小时后交易仍未触及任何其他屏障，时间限制将触发平仓

#### 三重屏障方法的优势

1. **多维度风险管理**：不仅考虑价格变动，还考虑时间因素，全方位保护资本。
2. **执行自动化**：设置后，整个交易生命周期自动管理，无需手动监控。
3. **心理压力减轻**：预先设定的退出规则减少交易过程中的情绪决策。
4. **资金管理优化**：帮助确保单笔交易损失不会过大，保持账户长期可持续性。
5. **灵活适应不同市场**：参数可调整以适应不同市场条件和交易时间框架。

有效的三重屏障配置是成功交易的关键。通过调整这些参数，您可以优化风险回报比，并根据市场条件和个人风险偏好定制交易策略。

### CCI策略的优势和注意事项

#### 优势
- **多功能性**：CCI是一个多功能的指标，可以在各种市场条件下工作。
- **偏差测量**：它通过测量当前价格与历史平均价格的偏差来识别超买和超卖条件。
- **波动捕捉**：特别适合在波动性市场中捕捉短期的价格反转机会。
- **明确的信号**：提供明确的进场和出场信号，减少交易中的主观决策。
- **灵活配置**：可以根据不同的市场条件和交易风格调整参数。

#### 注意事项
- **趋势市场限制**：在强趋势市场中，CCI可能会在超买或超卖区域停留较长时间，可能导致过早进入反趋势交易。
- **确认信号**：建议与其他指标（如移动平均线、RSI或MACD）结合使用以确认信号。
- **适当时间周期**：确保选择适合您交易风格的时间周期。较短的时间周期产生更多但可能更嘈杂的信号，较长的时间周期产生更少但可能更可靠的信号。
- **风险管理**：三重屏障方法提供了良好的风险管理框架，但仍需根据您的风险承受能力和账户规模进行适当调整。
- **回测验证**：在实盘交易前，建议先对您的CCI策略配置进行历史数据回测，以验证其在不同市场条件下的表现。
