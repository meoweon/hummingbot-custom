### 中文版文档

#### 灵活网格策略用户指南

##### 1. 策略概述
灵活网格策略（Flexible Grid Strategy）是一种基于价格区间的自动化交易策略，适用于加密货币永续合约市场（如 OKX Perpetual）。该策略通过在用户定义的价格范围内设置多个交易层级（Levels），在价格波动中自动执行开仓和止盈操作，旨在捕捉市场波动带来的利润。

**核心特点**：
- **多层网格**：在指定价格区间内自动划分多个层级，每个层级有独立的开仓和止盈参数。
- **支持多空双开**：可以同时运行做多（`BUY`）和做空（`SELL`）网格，适应不同市场趋势。
- **动态价格跟踪**：基于市场中间价格（`mid_price`）和极值价格（`highest_price`/`lowest_price`），实现反弹开仓和止盈。
- **灵活订单类型**：支持被动限价单（`LIMIT_MAKER`）和市价单（`MARKET`），满足不同交易需求。

**适用场景**：
- 波动市场：价格在一定范围内震荡时，通过低买高卖获利。
- 多空双向：同时运行多空网格，适合不确定趋势的市场。
- 自动化交易：无需手动干预，策略自动管理订单和仓位。

##### 2. 策略参数说明
以下是策略的主要参数及其含义，基于配置界面（截图）。

###### 基本配置
- **交易所**（`connector_name`）：
  - 选择交易平台，例如 `okx_perpetual`。
  - 示例：`okx_perpetual`
- **交易对**（`trading_pair`）：
  - 指定交易的币种对，例如 `BTC-USDT`。
  - 示例：`BTC-USDT`

###### 图表配置
- **K线数据源**（`candles_connector`）：
  - 用于获取历史K线数据的交易所，通常与 `connector_name` 相同。
  - 示例：`okx_perpetual`
- **K线间隔**（`interval`）：
  - 图表显示的K线时间间隔，例如 `1m`（1分钟）。
  - 示例：`1m`
- **展示天数**（`days_to_visualize`）：
  - 图表显示的历史数据天数。
  - 示例：1（1天）

###### 资金配置
- **总资金**（`total_amount_quote`）：
  - 策略使用的总资金，单位为报价货币（例如 USDT）。
  - 示例：1000（1000 USDT）
- **最小订单金额**（`min_order_amount_quote`）：
  - 每个订单的最小资金量，防止订单金额过小。
  - 示例：10（10 USDT）
- **杠杆**（`leverage`）：
  - 设置交易杠杆倍数，放大资金使用效率。
  - 示例：10（10倍杠杆）

###### 高级配置
- **网格范围数量**（`num_ranges`）：
  - 策略中独立的网格范围数量，每个范围是一个子网格。
  - 示例：1（1个范围）
- **持仓模式**（`position_mode`）：
  - 选择持仓模式，`对冲模式`（支持同时持有多空仓位），`单向模式`（仅支持单方向）。
  - 示例：`对冲模式`
- **最大开仓订单数**（`max_open_orders`）：
  - 允许同时存在的未成交开仓订单数量上限。
  - 示例：100
- **订单频率(秒)**（`order_frequency`）：
  - 策略检查和更新订单的频率，单位为秒。
  - 示例：5（每5秒检查一次）

###### 网格范围配置
每个网格范围有以下参数：
- **方向**（`side`）：
  - 交易方向，`BUY`（做多）或 `SELL`（做空）。
  - 示例：`BUY`
- **起始价格**（`start_price`）和 **结束价格**（`end_price`）：
  - 网格范围的价格区间，层级价格将均匀分布在此区间。
  - 示例：83422.32 ~ 85650.10
- **资金分配 %**（`total_amount_pct`）：
  - 该范围占总资金的百分比，所有范围的占比之和应为 100%。
  - 示例：50（50%）
- **激活边界**（`activation_bounds`）：
  - 控制订单激活和取消的价格范围，单位为比例。每个网格范围可以设置独立的激活边界。
  - 示例：0.01（1%）
- **网格层级数**（`n_levels`）：
  - 每个网格范围内的层级数量，决定价格点位的分布。
  - 示例：1（1个层级）
- **开仓订单类型**（`open_order_type`）和 **止盈订单类型**（`take_profit_order_type`）：
  - 选择订单类型，`被动限价单`（限价单）或 `市价单`（市价单）。
  - 示例：`被动限价单`（开仓），`限价单`（止盈）

###### 三重障碍配置
每个网格范围可以设置独立的风险管理参数，包括：
- **止盈比例**（`take_profit_ratio`）：
  - 达到该盈利比例时触发止盈。
  - 示例：0.03（3%）
- **止损比例**（`stop_loss_ratio`）：
  - 达到该亏损比例时触发止损。
  - 示例：0.05（5%）
- **追踪止损激活比例**（`trailing_stop_activation_ratio`）：
  - 当盈利达到该比例时，激活追踪止损功能。
  - 示例：0.03（3%）
- **追踪止损比例**（`trailing_stop_ratio`）：
  - 价格回撤该比例时触发追踪止损。
  - 示例：0.02（2%）
- **时间限制(分钟)**（`time_limit`）：
  - 持仓时间达到该限制时自动平仓。
  - 示例：1440（24小时）

###### 网格层级配置
- **开仓比例**（`open_ratio`）：
  - 下一层触发价格相对于上一层开仓价格的上升比例（做空）或下降比例（做多）。
  - 示例：0.0200（2%）
- **开仓回弹比例**（`open_rebound_ratio`）：
  - 开仓时的回弹比例，基于 `highest_price`（做空）或 `lowest_price`（做多）。
  - 示例：0.0100（1%）
- **止盈比例**（`take_profit_ratio`）：
  - 止盈价格相对于开仓价格的下降比例（做空）或上升比例（做多）。
  - 示例：0.0300（3%）
- **止盈回弹比例**（`take_profit_rebound_ratio`）：
  - 止盈时的回弹比例，基于 `lowest_price`（做空）或 `highest_price`（做多）。
  - 示例：0.0150（1.5%）
- **资金比例**（`amount_quote_ratio`）：
  - 该层级占范围资金的比例，所有层级的比例之和应为 100%。
  - 示例：0.2800（28%）

##### 3. 使用方法

###### 步骤 1：启动策略
1. **进入配置界面**：
   - 启动 Hummingbot，进入策略配置页面，选择"灵活网格策略"。
2. **填写基本参数**：
   - 设置交易所（`okx_perpetual`）、交易对（`BTC-USDT`）等。
3. **配置图表参数**：
   - 设置K线数据源、K线间隔（`1m`）和展示天数（`1`）。
4. **资金配置**：
   - 设置总资金、最小订单金额和杠杆。
5. **高级配置**：
   - 设置网格范围数量、持仓模式、最大开仓订单数、订单频率。
6. **配置网格范围**：
   - 为每个范围指定方向（`BUY` 或 `SELL`）、价格区间（例如 83422.32~85650.10）、资金分配百分比（50%）。
   - 选择网格层级数和订单类型（`被动限价单` 或 `市价单`）。
7. **配置层级参数**：
   - 为每个层级指定开仓比例、止盈比例、回弹比例和资金比例。
8. **保存并启动**：
   - 点击"保存配置"，启动策略，Hummingbot 将自动运行。

###### 步骤 2：监控和调整
- **监控**：
  - 查看图表，网格层级会以水平线显示（绿色为 `BUY`，红色为 `SELL`）。
  - 检查日志，了解订单状态（未成交、已开仓、已止盈）。
- **调整**：
  - 如果市场波动较大，可降低 `订单频率`（例如 5秒），提高响应速度。
  - 如果订单未成交率高，可调整各网格范围的 `激活边界`（例如 0.005）或使用 `市价单`。

##### 4. 策略运行逻辑
1. **层级触发**：
   - 每个层级有一个触发价格（基于 `start_price` 和 `end_price` 均匀分布）。
   - 做多（`BUY`）：当 `mid_price` 跌至触发价格，进入 `WAITING_OPEN_REBOUND`，跟踪 `lowest_price`。
   - 做空（`SELL`）：当 `mid_price` 涨至触发价格，进入 `WAITING_OPEN_REBOUND`，跟踪 `highest_price`。
2. **开仓回弹**：
   - 做多：当 `mid_price` 从 `lowest_price` 回弹超过 `open_rebound_ratio`，触发开仓。
   - 做空：当 `mid_price` 从 `highest_price` 下跌超过 `open_rebound_ratio`，触发开仓。
3. **止盈回弹**：
   - 做多：当 `mid_price` 涨至 `actual_open_price * (1 + take_profit_ratio)`，进入 `WAITING_TP_REBOUND`，跟踪 `highest_price`。
   - 做空：当 `mid_price` 跌至 `actual_open_price * (1 - take_profit_ratio)`，进入 `WAITING_TP_REBOUND`，跟踪 `lowest_price`。
   - 止盈价格基于回弹比例（`take_profit_rebound_ratio`）确定。
4. **订单管理**：
   - 每 `order_frequency` 秒检查一次，更新 `highest_price` 和 `lowest_price`，创建或取消订单。
   - 未成交订单数量受 `max_open_orders` 限制。

##### 5. 示例场景
###### 场景：单方向做多网格
- **配置**：
  - 总资金：1000 USDT
  - 网格范围数量：1（Range 1，`BUY`）
  - 价格区间：83422.32~85650.10
  - 层级数：1
  - 资金分配：50%（500 USDT）
  - 资金比例：1.0（100%）
  - 开仓回弹比例：0.01，止盈比例：0.03
  - 订单频率：5秒
- **运行**：
  - `mid_price` 跌至 83422.32，触发，进入 `WAITING_OPEN_REBOUND`。
  - `mid_price` 跌至 83000（`lowest_price` = 83000），回弹至 83160（\( 83000 \times 1.01 \)，满足回弹条件）。
  - 5秒时，挂买单（`被动限价单`），价格 83160，数量 500 USDT / 83160 ≈ 0.00602 BTC。
  - `mid_price` 涨至 85650（\( 83160 \times 1.03 \)，触发止盈），止盈卖出。

###### 场景：多空双开
- **配置**：
  - 网格范围数量：2
  - Range 1：`BUY`，80000~82000，资金分配 50%
  - Range 2：`SELL`，82000~84000，资金分配 50%
  - 层级数：1
- **运行**：
  - Range 1 做多：价格跌至 80000，触发开仓，涨至 82400 止盈。
  - Range 2 做空：价格涨至 84000，触发开仓，跌至 81600 止盈。

##### 6. 注意事项
- **市场风险**：
  - 网格策略适合震荡市场，若市场单边趋势（例如持续上涨），可能导致资金占用或亏损。
- **参数调整**：
  - 高波动市场：降低 `订单频率`（例如 5秒），使用 `市价单`。
  - 低波动市场：使用 `被动限价单`，设置较大的各网格范围 `激活边界`（例如 0.02）。
- **交易所限制**：
  - 确保 API 密钥权限正确，关注交易所的订单数量和频率限制。
- **资金管理**：
  - 合理分配资金（`total_amount_pct` 和 `amount_quote_ratio`），避免单一层级占用过多资金。

##### 7. 常见问题
- **Q：为什么订单未成交？**
  - A：可能是各网格范围的 `激活边界` 过小，导致订单频繁取消；或市场波动不足，建议调整 `订单频率` 或使用 `市价单`。
- **Q：如何设置多空双开？**
  - A：将 `网格范围数量` 设为 2，Range 1 设为 `BUY`，Range 2 设为 `SELL`，并分配资金占比。
- **Q：`highest_price` 和 `lowest_price` 多久更新一次？**
  - A：受 `订单频率` 限制，例如 5秒更新一次。若需更快响应，可降低 `订单频率`。
